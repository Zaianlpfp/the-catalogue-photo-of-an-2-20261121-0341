# The Cordless Extension Cord

A catalogue photograph of an impossible gadget: a premium orange-and-white
extension cord reel whose two ends are plugged **into each other**, forming a
neat closed loop — a cord that reaches nothing. Shot as a studio product
photograph on a seamless light-grey background, soft shadow beneath, with
exactly one accessory: a single unused wall socket, slightly out of focus, on
the background wall. The tiny embossed label on the reel reads `CORDLESS`.

The hero image is a photorealistic studio shot made inside the recorded build
session (`assets/hero.png`, 1024×1024). The program copies it deterministically
to `/output/entry.png` — no network, no randomness, no timestamps.

## Run it

```sh
node main.ts
```

Requires Node 22. Writes `/output/entry.png` (505,453 bytes, 1024×1024 PNG).
Set `MAKEFUN_OUTPUT_DIR` to write `entry.png` somewhere else instead.
